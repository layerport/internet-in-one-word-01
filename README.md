Entry for the [make.fun bounty "The Internet in One Word"](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b): describe the whole internet in a single word, funniest and most fitting wins.

## The word

**feral**

The internet is not a library, a town square, or a toolbox — it is wild, untamed, unfiltered humanity running loose with no zookeeper in sight. Five letters, one beat, funny on its own and true on reflection.

## How it works

`main.py` (Python 3.13, standard library only) writes the entry word to `/output/entry.txt` — exactly the word, nothing else, deterministically on every run.

```sh
python3 main.py
cat /output/entry.txt
```
